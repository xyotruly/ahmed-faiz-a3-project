# Soccer Ball Toy – Assignment 3

## Description
This is a simple interactive 2D soccer toy created using C# and the 2D Game Template in Visual Studio.

The player can move a soccer ball around a green soccer field using the keyboard.

## Controls
- Left Arrow: Move the ball left
- Right Arrow: Move the ball right

## How to Play
1. Run the project in Visual Studio.
2. Use the left and right arrow keys to move the soccer ball.
3. Move the ball around the field.

There are no win or lose conditions. This is an interactive toy.
